# SPEEDTEXT

Telegram Mini App для скорочтения (RSVP): слова идут по одному, опорная буква стоит в одной точке экрана и выделена цветом.

Проектный документ лежит в общей папке проекта: `design/speed-reader-design.md`.

## Запуск

```sh
npm install
npm run dev     # http://localhost:5173
npm test        # тесты движка
npm run build   # статика в dist/
```

## Сайт

Каждый пуш в `main` собирается и выкладывается на GitHub Pages: https://mr-erick.github.io/chitalishe/

## Управление

| Действие | Телефон | ПК |
|---|---|---|
| Плей / пауза | тап по центру | пробел |
| Предложение назад / вперёд | свайп вправо / влево | ← / → |
| Скорость ±25 слов/мин | свайп вверх / вниз | ↑ / ↓ |
| Назад к тексту | кнопка «Назад» Telegram | Esc |

## Что умеет

- Библиотека книг на устройстве: файлы TXT (UTF-8, CP1251, KOI8-R), DOCX и FB2 или вставленный текст. DOC пока просит пересохранить в DOCX.
- Главы: по заголовкам в TXT («Глава 3», «Часть II», «***»), по стилям заголовков в DOCX; текст без глав делится на части по ~2000 слов.
- Место чтения и скорость каждой книги сохраняются сами; закладки с заметками.
- Общие настройки: постоянная скорость или разгон, шрифт, размер, цвет опорной буквы, фон, откат после паузы, поведение в конце главы, вибрация.

## Структура

- `src/engine/` — разбор текста на слова, опорная буква, тайминги (без React, покрыто тестами).
- `src/books/` — разбор файлов, хранение (IndexedDB + localStorage), каталог бесплатной библиотеки (`catalog.ts`, `library.json`).
- `src/ui/` — экраны и управление.
- `public/books/library/` — тексты книг бесплатной библиотеки.

Памятка для разработки с Claude: `CLAUDE.md`.
- `src/telegram.ts` — обёртка над Telegram WebApp, вне Telegram ничего не делает.
