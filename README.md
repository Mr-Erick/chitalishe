# Читалище

Telegram Mini App для скорочтения (RSVP): слова идут по одному, опорная буква стоит в одной точке экрана и выделена цветом.

Проектный документ лежит в общей папке проекта: `design/speed-reader-design.md`.

## Запуск

```sh
npm install
npm run dev     # http://localhost:5173
npm test        # тесты движка
npm run build   # статика в dist/
```

## Управление

| Действие | Телефон | ПК |
|---|---|---|
| Плей / пауза | тап по центру | пробел |
| Предложение назад / вперёд | свайп вправо / влево | ← / → |
| Скорость ±25 слов/мин | свайп вверх / вниз | ↑ / ↓ |
| Назад к тексту | кнопка «Назад» Telegram | Esc |

## Структура

- `src/engine/` — разбор текста на слова, опорная буква, тайминги (без React, покрыто тестами).
- `src/ui/` — экраны и управление.
- `src/telegram.ts` — обёртка над Telegram WebApp, вне Telegram ничего не делает.
